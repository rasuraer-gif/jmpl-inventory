Moulding / Production Stage 1

The starting manufacturing stage. Raw compound rubber is moulded using designated part moulds (Mould 1 through Mould 5). Yield is calculated by lifts completed multiplied by cavities. Batches can be run In-House or dispatched to Subcontractors.

Identity & Tracking

Batch Number Generation & Allocation

1
Production Batch Formula

Batches are assigned a unique, traceable ID structured exactly like production batch creation:

[JMREF No] - [TR No] - [DD] - [Shift] - [Type] - [Press No]
2
Internal Batch No (IB)

A auto-generated, sequential integer matching sequence (e.g. IB: 1045) generated globally across all stages.

3
Properties Tracked

Part Number, Description, Mould Type, and Process Flow mapped dynamically based on the JMREF No and Mould No.

ℹ️ Code Breakdown

dayStr = Date.split('-')[2]
shiftCode = Shift === 'night' ? 'N' : 'D'
typeCode = ProdType === 'subcontractor' ? 'S' : 'I'
batchNo = `${jmrefNo}-${trNo}-${dayStr}-${shiftCode}-${typeCode}-${pressNo}`

Ensures complete traceability of shift, machine (press), manufacturing date, vendor/subcontractor, and tooling reference.

Movement Control

Process & Move Stage Calculations

➔ Output Defaulting

When moving a batch to the next stage, the Output Quantity is pre-filled to match the input quantity by default. This makes operations faster and cleaner while keeping the input fully editable.

⚠️ Yield Loss Tracker

Any difference between input and output is automatically calculated and saved as a loss record:
Loss Qty = Input Qty - Output Qty. Triggers automatic entries in the Loss Database.

🔄 Sub-Batch Spills

Allows partial quantities to split into secondary sub-batches to be processed under different operators/subcontractors, maintaining sequence lineages through parent reference ids.

Reconciliation & Import

Batch-wise Excel Bulk Import

The new bulk upload feature enables importing multi-row manufacturing entries from a standardized Excel spreadsheet, complete with automated database mappings and validation safeguards:

✓
Auto-Derivations: Part No, Description, Mould Type, Process Flow, Batch No, and Internal Batch No are automatically populated based on JMREF No & Mould No.
✓
Database Validation: Verifies JMREF No exists in Master, Operator and Subcontractors match active registers, and confirms the generated batch number is not a duplicate.

Import Steps Workflow:

1. Upload Excel spreadsheet in the Bulk Upload tab.
2. Preview validation preview panel (errors flagged in red).
3. Confirm (blocks import if active errors exist).
4. Redirects to Success table to select and bulk print barcode labels.
